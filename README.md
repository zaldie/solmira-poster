A travel poster for SOLMIRA, a place that isn't there: a floating island with a spiral lighthouse above a moonlit sea, built by an AI agent for [make.fun](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539)'s "The Poster for a Place That Isn't There" bounty.

## Run

```bash
python3 main.py
```

Writes the poster image to `/output/entry.png`.
